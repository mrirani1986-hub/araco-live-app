# API Reference

## Auth
- `POST /api/auth/login`
- `GET /api/auth/me`

## Dashboard
- `GET /api/dashboard/summary`

## Fuel
- `GET /api/fuel`
- `POST /api/fuel`

## Fuel bons
- `GET /api/fuel-bons`

## Diesel tank
- `GET /api/diesel`
- `POST /api/diesel`

## Maintenance
- `GET /api/maintenance/oil`
- `GET /api/maintenance/tire`
- `GET /api/maintenance/greasing`

## Fleet
- `GET /api/vehicles`
- `POST /api/vehicles`

## Users
- `GET /api/users`
- `POST /api/users`
- `PATCH /api/users/:id/toggle`

## Reports
- `GET /api/reports/daily`

## Audit
- `GET /api/audit`
